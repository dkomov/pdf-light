# Changelog

Notable changes are recorded here. Version numbers describe project releases; Git history records actual commits.

## 1.1.0 — 2026-11-16

- Add system-language selection and instant switching between English, Russian, German, French, Spanish, Japanese, and Simplified Chinese.
- Share UI and worker translations; localize progress, results, errors, menus and accessibility labels.
- Accept comma and dot decimal target input; format displayed numbers for the selected locale.
- Build a standalone Apple Silicon app from public, pinned Python dependencies.
- Include third-party license files and verify the signed bundle and isolated imports during building.
- Add localization regression tests, style configuration, CI, original demo artwork, and open-source documentation.
- Publish project code under MIT.

## 1.0.0 — local prototype, 2026-11-16

- Native AppKit window with drag/drop, PDFKit preview, target size, three compression modes, cancellation, and Save a copy.
- Data recompression, bounded path-coordinate rounding, conservative full-page opaque-mask repair, and optional JPEG recompression.
- Per-page text and rendering checks with PDFium, plus an independent CoreGraphics comparison.
- Initial safety regression tests and standalone local bundle.

This prototype entry records the local app, not an earlier public release.
